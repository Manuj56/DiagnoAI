# DiagnoAI 🩺🤖

DiagnoAI is a **Machine Learning-based disease prediction system** that helps users get a preliminary prediction of possible diseases based on their symptoms.

The system takes user-provided symptoms as input, processes them using trained ML models, and provides a predicted disease along with a simple and user-friendly interface.

## ✨ Features

- 🩺 Symptom-based disease prediction
- 🤖 Machine Learning-powered predictions
- 📊 Multiple disease classification
- 🖥️ Simple and interactive UI
- ⚡ Fast prediction results

## 🛠️ Tech Stack

**Python | Machine Learning | Scikit-learn | Pandas | NumPy | Streamlit**

## 🔄 Workflow

**Symptoms → Data Processing → ML Model → Prediction → Result**

## 🎯 Purpose

Built to demonstrate how **Machine Learning can be applied to healthcare-related prediction problems** through an easy-to-use web application.
